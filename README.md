## Project Overview

Urban expansion is one of the most significant indicators of land use and land cover change. Monitoring urban growth using satellite imagery helps governments, urban planners, and environmental agencies make informed decisions regarding sustainable development.

This project aims to develop and evaluate Convolutional Neural Network (CNN) models for detecting urbanized regions from satellite imagery. The study compares a custom CNN architecture with transfer learning approaches including MobileNetV2 and ResNet50.

---

## Objectives

* Detect urbanized areas from satellite imagery.
* Compare CNN and transfer learning models.
* Evaluate model performance using multiple metrics.
* Visualize model predictions and important image regions.
